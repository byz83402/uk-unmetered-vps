## 买之前必须知道的几个限制

**这不是大陆优化线路，别指望国内直连快。** 丽萨英国节点走的是英国 BGP 国际网络，官方页面自己就写着「非大陆直连优化网络，建议中转使用」。从国内直连延迟 200ms 以上，联通和部分地区移动直连还行，**电信用户体验最差**，建议走香港或日本中转，官方支持中转业务，可以提工单咨询。

三网走向大致是这样：电信去程经美国圣何塞转 NTT 到伦敦，联通走洛杉矶转 TATA 进欧洲，移动走 CMI 从香港经新加坡到欧洲；回程电信走 RETN 经德国 peer 直连回国，移动走 RETN 对接伦敦 CMI 直连回国，联通走 Cogent 经荷兰、德国回国。如果你主要做的是海外业务、服务的是英国本地用户，这个延迟不是问题；如果是国内建站、打游戏，这台机器不合适。

**不限流量档的带宽只有 200Mbps 和 500Mbps。** 对比 OVH 最高 3Gbps，这个数字不好看。但带宽和 IP 属性在同一个套餐里很难兼得，你要住宅 IP，就得接受端口被限。

**上游 ISP 的说法不统一。** 公开资料里分别提到 Sky Telecom（天空电讯）和 Virgin Media O2 两家英国本土宽带运营商，后者是较新的说法，可能反映了节点演进过程。下单前想知道当前节点归属哪家，直接开工单问最稳。

**「IP 纯净度」这件事本身没有统一标准。** 市面上不少检测网站给出的欺诈值评分并没有公开评分依据，IP 地址也没有严格意义上的「纯净」「干净」「新老」之分，TikTok 这类平台有自己的 IP 地址库和检测手段。所以你看到任何「风险分 0」的宣传，都只能当参考，真正的验证方式是拿你要用的平台在退款期内自己跑一遍。

**不适合的人**：纯国内建站追求低延迟的、预算压到极限只要最便宜 VPS 的、需要大陆优化线路对延迟敏感的。这三类人去看香港或日本节点更合适。

## 常见问题

**不限流量是真的完全不限吗？**

是流量不设月度上限，但端口带宽固定死在 200Mbps 或 500Mbps。换句话说，你一个月能跑多少，取决于端口跑多久，而不是被一个流量计数器卡住。这跟「带宽不限、流量 1000GB/月」的套餐是两种完全不同的产品，买之前看清楚标的是哪一项。

**国内访问慢怎么办？**

配香港或日本中转，官方支持中转业务，提工单问具体方案。装好系统后先开 BBR 加速，对英国到国内的链路改善明显。电信用户受影响最大，如果业务允许，尽量用联通或移动网络操作。

**能解锁 BBC iPlayer 吗？**

按第三方测评的实测口径，Netflix、Disney+、BBC iPlayer、ITV Hub、Channel 4&5、BritBox、Acorn TV、Discovery+、Paramount+、DAZN、Rakuten、Hotstar、Shudder，以及 ChatGPT、Steam 货币区域都在可解锁范围内。IP 属性会随时间变化，具体到你手上那个 IP，以开通后实测为准。

**466 元/年的特价版和常规年付折后的 587 元差在哪？**

硬件配置和带宽完全一样，差别只在流量：特价版 2TB/月，常规基础版 6TB/月。月用量稳定在 2TB 以内选特价版，省钱；超过 2TB 就回常规基础版，否则等于花一半的钱买三分之一的量，摊到每 GB 反而更贵。
